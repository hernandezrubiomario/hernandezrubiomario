### 🧪 Proyectos destacados

**[homelab-iac](https://github.com/hernandezrubiomario/homelab-iac)** — laboratorio de infraestructura como código de extremo a extremo: aprovisionamiento con Terraform + Cloud-Init sobre KVM, IPAM dinámico con NetBox, identidad/DNS centralizados con FreeIPA, y configuración con Ansible.

```
Terraform → KVM → NetBox → Cloud-Init → Ansible → FreeIPA → DNS
```

**[ha-postgresql-patroni](https://github.com/hernandezrubiomario/ha-postgresql-patroni)** — clúster PostgreSQL en alta disponibilidad (Patroni + etcd + HAProxy + Keepalived), con monitorización completa en Prometheus/Grafana y pruebas reales de failover documentadas. Es el clúster HA que reutiliza `homelab-iac` como base de datos.
